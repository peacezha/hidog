# HiDog 使用示例

本目录包含 HiDog 项目的各种使用示例，帮助用户快速上手。

## 示例列表

### 基础示例

1. **hello-world.js** - 最简单的 HiDog 应用
2. **config-example.js** - 配置使用示例
3. **api-example.js** - API 接口示例

### 高级示例

4. **database-integration.js** - 数据库集成示例
5. **authentication.js** - 身份验证示例
6. **middleware-example.js** - 中间件使用示例

## 运行示例

```bash
# 进入示例目录
cd examples

# 运行基础示例
node hello-world.js

# 运行特定示例
node api-example.js
```

## 示例说明

每个示例文件都包含：
- 详细的代码注释
- 使用说明
- 预期输出
- 常见问题解决方案

请根据您的需求选择相应的示例进行学习和参考。
